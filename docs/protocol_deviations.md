No deviation changed C1: all four ten-seed drug-bootstrap intervals and both crossed-bootstrap intervals remained far above the 0.10 materiality threshold. Ten-seed completion changed the secondary NCI60 C2 Holm value from 0.0472 to 0.0536. The complete post-confirmation source-only grid selected tuned ITENS (0.35018) over the locked MF configuration recomputed on the matched retrospective population (0.33400), exposing the historical tuning imbalance; nevertheless, tuned ITENS remained below locked MF on primary GDSCv1 shared entities by 0.01861 (95% BCa interval 0.00645 to 0.03292 in the MF-favoring direction) and did not differ on NCI60. The retrospective feature registry includes 300,507 source pairs, 822 cells and 459 drugs; the historical development population remains 293,194 pairs, 819 cells and 451 drugs. These retrospective sensitivities cannot restore prospective status and are not substituted for the original locked claims.
